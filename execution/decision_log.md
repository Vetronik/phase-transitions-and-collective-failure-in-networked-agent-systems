# Execution decisions

The pilot and confirmation allocations were reduced because the transparent reference Python update loop is the correctness baseline and the full discovery grid was too expensive for this session. The exact full grid remains encoded in the protocol; the reduced allocations are recorded as deviations.

The confirmation run was completed before terminal error-vector storage was added. Rather than overwrite that immutable result, a separate mechanism batch was run with the new schema. This preserves the confirmation effects and supplies independent covariance evidence.

The complete-graph benchmark was intentionally treated as a sanity check. Its finite-time susceptibility maximum remains at the upper tested coupling edge for all four sizes, so no critical point, exponent, or thermodynamic phase claim was promoted to the manuscript.
